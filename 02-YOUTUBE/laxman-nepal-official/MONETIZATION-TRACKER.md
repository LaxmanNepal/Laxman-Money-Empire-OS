## Decision rules

- If a topic produces high views and good subscriber conversion: make a follow-up.
- If views are high but retention is poor: fix the opening and structure.
- If CTR is weak but retention is strong: test title/thumbnail.
- If CTR is strong but retention is weak: the packaging overpromises.
- If both are weak: stop repeating the concept without changing the underlying idea.
- Never delete a video simply because it performs badly without understanding why.
