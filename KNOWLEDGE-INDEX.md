## 3. YouTube operating system

Research → score topic → verify facts → choose format → hook → script → record/demo → edit → thumbnail → title → publish → measure → learn.

Do not optimize for upload volume alone. YouTube says monetized channels must provide original/authentic value and warns against repetitive, mass-produced or reused content. Automation should remove repetitive production work while preserving original research, demonstrations, commentary and editorial judgment.

Current documented full YPP entry: 1,000 subscribers plus either 4,000 qualified public watch hours in the previous 12 months or 10M qualified public Shorts views in the previous 90 days, subject to policies and review. Keep thresholds versioned because platform rules can change.

## 5. Prompt architecture

Every serious prompt should contain:

- Role
- User/business context
- Exact objective
- Audience
- Available evidence
- Constraints
- Required output format
- Verification requirements
- Monetization implication
- Success metric
- Stop conditions

Never use a vague "make it better" prompt when a measurable objective can be specified.

## 6. Automation architecture

Trigger → fetch → validate → transform → store → publish → notify → log → retry → human review where needed.

Recommended primitives:
- GitHub Actions
- APIs
- JSON
- scheduled workflows
- static web apps
- serverless functions when necessary
- analytics snapshots

Never commit secrets.

## 7. Business decision score

Score opportunities 1–5 for:

- demand
- willingness to pay
- distribution advantage
- time to first revenue
- build effort
- automation potential
- ownership
- defensibility
- trust/legal/platform risk

Reject attractive ideas with weak distribution or no monetization path.

## 9. Operating cadence

Daily: execute the highest-leverage action.

Weekly: research → publish → improve asset → analyze → choose next experiment.

Monthly: revenue review, channel review, product review, kill weak projects, double down on winners.

## 10. Hard rules

- Never fabricate statistics, financial data, testimonials, rankings or earnings.
- Never promise guaranteed income.
- Verify current platform rules before making monetization claims.
- Verify licenses before redistributing media, streams or datasets.
- Financial information must separate facts, calculations, assumptions and opinion.
- AI-generated content must be materially useful and original.
- Never put API keys, cookies, passwords or tokens in Git.
- Build distribution and monetization alongside software.
