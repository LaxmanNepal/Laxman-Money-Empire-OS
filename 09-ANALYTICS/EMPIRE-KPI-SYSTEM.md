# Empire KPI System

## North-star metric

**Profitable useful attention**: users who discover Laxman's content, trust it, use an owned asset and eventually create measurable economic value.

## Funnel

`Reach → View → Engage → Visit → Return → Lead → Purchase → Retain`

## YouTube KPIs

- Subscribers
- Qualified public watch hours
- Shorts views
- Returning viewers
- Views/video
- Average view duration
- Audience retention
- Click-through rate where available
- Subscribers gained/video
- Top topic clusters

## Facebook KPIs

- Reach
- Video views
- Average watch time
- Shares
- Saves
- Profile visits
- Followers gained
- Link clicks
- Revenue/qualified lead

## Website KPIs

- Users
- Sessions
- Search clicks/impressions
- Top landing pages
- Returning users
- Tool usage
- Conversion rate
- Ad revenue where applicable
- Affiliate clicks
- Product purchases

## Business KPIs

- Revenue by source
- Gross margin where known
- Leads
- Lead-to-sale rate
- Average order value
- Recurring revenue
- Customer acquisition cost
- Retention/churn
- Hours spent per revenue unit

## Decision thresholds

Do not invent universal benchmarks. Establish a baseline, run a controlled change, then compare.

## Weekly CEO report

1. Biggest growth.
2. Biggest decline.
3. Best content.
4. Best acquisition source.
5. Best monetization source.
6. Biggest wasted effort.
7. One experiment to run.
8. One thing to stop.
9. Three actions for next week.

## Red flags

- Views rising but no returning viewers.
- Traffic rising but no conversion.
- Revenue rising only because of one temporary source.
- Production volume rising while quality falls.
- Increasing dependency on one platform.
- Large engineering work without user evidence.
